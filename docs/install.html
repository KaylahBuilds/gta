INSTALL · v0.3.0

Ten minutes, once

Three files into a folder and a keypress. If you've installed a script mod before, skip to step 2.

Read this first
Story mode only. Loading script mods into GTA Online will get your account banned. On Enhanced, launch the game without BattlEye.

What you need first

GTA V
Legacy or Enhanced, story mode
Script Hook V
the build for your edition
ScriptHookVDotNet Enhanced
1.1.0.6+
Install this even on Legacy. The standard build won't load the mod on Enhanced.
.NET Framework 4.8
and the Visual C++ 2019 x64 redistributable

Install

01
Base tools into the game folder
Script Hook V and SHVDNE go in the folder with GTA5.exe. Make a scripts folder there if you don't have one.
02
Three files into scripts
<game root>/scripts/ OnTheBlade.dll LemonUI.SHVDN3.dll iFruitAddon2.dll
Don't put ScriptHookVDotNet3.dll in there — a second copy breaks script loading. It belongs in the game root only.
03
Load story mode and press F5
You should get an On The Blade loaded notification. If a key clashes with another mod, both are rebindable in config.json.

Keys

F5
Operations — roster, territory, upgrades, property, muscle
F1
Phone — status, recall everyone, fast travel
Insert
Reload scripts. Safe — releases every ped the mod owns and saves first
